# EduMaterial

Plataforma em desenvolvimento para facilitar a descoberta, a organização e a adaptação de materiais didáticos por professores.

## Sobre o projeto

O EduMaterial é um projeto de portfólio que simula o ciclo de desenvolvimento de um produto digital educacional, desde a investigação do problema até a implementação e os testes de qualidade.

A proposta inicial é investigar como professores encontram materiais didáticos, quais dificuldades enfrentam nesse processo e como uma plataforma poderia ajudá-los.

## Objetivo

Investigar um problema real do cotidiano docente e desenvolver uma solução digital orientada às necessidades dos usuários.

## Funcionalidades em estudo

- Catálogo de materiais didáticos.
- Busca e filtros.
- Visualização prévia dos materiais.
- Download de recursos.
- Possibilidade de adaptar materiais às necessidades de cada professor.

Essas funcionalidades são hipóteses iniciais e poderão mudar conforme os resultados da pesquisa com usuários.

## Processo de desenvolvimento

1. **Product Discovery:** investigar o problema e conhecer os usuários.
2. **Product Ownership:** definir requisitos, histórias de usuário e prioridades.
3. **UX/UI Design:** estruturar a experiência e as interfaces.
4. **Desenvolvimento:** implementar a solução.
5. **Quality Assurance (QA):** planejar e executar testes, registrar defeitos e verificar correções.

## Tecnologias e ferramentas

As tecnologias serão definidas conforme os requisitos e as decisões de arquitetura do projeto.

Ferramentas previstas para o processo: GitHub, Google Forms, Google Sheets e Figma.

## Status do projeto

**Fase atual:** estruturação inicial e planejamento da pesquisa com professores.

O problema e as funcionalidades ainda serão investigados e validados. O produto não está implementado.

## Portfólio

Este repositório documentará as decisões de produto, os artefatos de planejamento, o desenvolvimento e os testes realizados ao longo do projeto.
